## [2026-09-08] fix | линковка youth-клубов: «Under 18» и цепочки к неверному родителю

Пользователь заметил: после ручной правки команд Serie A стиль не распространился на
команды Under 18. Две причины в `kits/linked.py`:

1. **Суффикс `under18` отсутствовал** — «Inter Under 18» → `interunder18` не оканчивался
   ни на один известный суффикс (`u18`/`sub18`), поэтому все 20 команд Campionato Under 18
   (ITJ7) оставались самокорневыми и не наследовали киты.
2. **Фолбэк родителя выбирал любую команду с тем же префиксом** — «Fiorentina Primavera»
   (база `fiorentina`) не находила точного «Fiorentina», и кандидатом становилась
   «Fiorentina Under 18»; так Primavera/U20 цеплялись к Under-18 вместо основного клуба
   (Roma U20 → Roma Under 18, Lecce Primavera → Lecce Under 18, ...).

Исправления:
- В `RESERVE_SUFFIXES` добавлены `under17`..`under23` (идут раньше коротких `uNN`).
- `_parent_of` переписан: родитель ищется только среди **основных** клубов (исключаются
  youth-имена через новые `RESERVE_PARENT_SUFFIXES` — без «b/c/2/3», чтобы не срезать
  хвосты «FC/BC/AC»), сначала точное/префиксное совпадение, затем подстрока (например
  «fiorentina» в «acffiorentina»), ближайшее имя побеждает. Дополнительно исключаются
  родители, чьё имя содержит **полное** имя клуба-ребёнка как подстроку — иначе «Rangers FC»/
  «Ha Noi FC»/«Delhi FC» цеплялись бы к «Cove Rangers FC»/«Cong An Ha Noi FC»/«Sudeva Delhi FC».

Ре-линковка итальянских клубов в `out/all/specs.json` (dry-run → apply): 43 клуба,
20 Under 18 получили правильного родителя, 8 неверных цепочек Primavera/U20 исправлены
(Roma U20→AS Roma, Fiorentina/Sassuolo/Lecce/Monza/Cesena/Lazio → основной клуб),
плюс Empoli/AlbinoLeffe Primavera доехали до своих корней. Дети наследуют палитру+киты
корня, помечаются `edited`. Редактор перезапущен на исправленных данных.

## [2026-09-03] session | первый прототип: батч-генератор + web-редактор

Создан standalone-проект kit-generator по итогам обсуждения: генерация скриптом, затем
ручной редактор, в котором клуб за клубом показываются логотип и цвета, а раскладка по
частям формы (футболка/шорты/гетры) и узор футболки назначаются схематично; «далее»
принимает и автогенерированные сочетания.

Ключевые решения:
- **Регионы из template_kit.png выводятся программно** (`kits/regions.py`): футболка
  y 0–418, шорты y 419–582, гетры y 583–766; швы/фон — чёрные. Второй регион (шорты+
  гетры слиты) разбит по координатам — теперь части формы красятся раздельно.
- **Затенение = зелёный канал шаблона** (трикотаж): результ = цвет_региона × (G/база),
  база 211 для футболки, 255 для шортов/гетр. Дёшево даёт вязаную фактуру.
- **Палитра клуба**: профильные TM-цвета → цвета из логотипа (ресайз 48×48, игнор
  прозрачности, квантование, топ по частоте+насыщенности) → нейтрали (white/black
  всегда в конце, дедуп по точному совпадению).
- **Узоры** (`kits/render.py`): plain/stripes/hoops/sash/halves; stripes/halves считаются
  по run-относительной x внутри связных регионов строки, чтобы перед/спинка/рукава
  разбивались независимо.
- **Автоподбор** (`kits/spec.py`): home = primary→футболка, secondary→шорты/гетры;
  away = третий цвет или нейтрал с максимальным контрастом; gk = максимально отличный
  от обоих, светлее при прочих равных. Проверено: 0 клубов с совпадающими home/away
  и 0 с тремя одинаковыми комплектами.
- **Экспорт в игру**: `export_game.py` → `images_teams/<league_id>/<club_id>_kit_01.png`,
  `_kit_02.png`, `_kit_gk.png`. Per-team GK требует правки `team.cpp` (см. NOTES.md).

Покрытие: 4406 клубов, палитра есть у 4401 (5 без логотипа/с невыразительным логотипом
получают белый/чёрный). Сгенерировано 13218 PNG (199 МБ) + specs.json.

Проверка редактора: `editor/server.py` отдаёт клубы/превью/логотипы, POST сохраняет
правки в specs.json, превью обновляется (проверено на PL-подмножестве, порт 9001).

## [2026-09-03] session | модель «6 комплектов + матчевый выбор»

По обсуждению с пользователем расширена модель китов (критика предложения и финальные
решения зафиксированы в диалоге):

- **Набор на клуб: main/white/black/reserve + gk1/gk2** (6 комплектов). Белый/чёрный —
  универсальные нейтрали для выездных; резервный — хроматический цвет из палитры, отличный
  от main/белого/чёрного; гк1/гк2 — два ярких цельных цвета из стандартного пула
  (зелёный/оранжевый/жёлтый/голубой/маджента).
- **Правило шортов/гетр**: цвет футболки, либо нейтрал (вторичный цвет клуба, если он
  белый/чёрный); у цельных белого/чёрного — всё в этот цвет.
- **Матчевая селекция** `pick_match_kits`: конвенция (home в main; гость переодевается
  при клаше футболок < 60 по RGB-дистанции; при остающемся клаше переодевается и home),
  ручной оверрайд `manual={"a","b"}`. Вратари выбираются на матч: из gk1/gk2 тот, что
  максимизирует мин-контраст к обеим полевым футболкам. Эталон на Python для переноса в C++.
- **Объём итерации**: только ассеты + спека + эталон селекции; интеграция в игру
  (team.cpp/меню) — отдельный шаг (см. NOTES.md).
- Исправлен баг `_pick_far` prefer_light (бонус давался тёмным, теперь светлым).
- Редактор расширен на 6 комплектов; правки помечают клуб `edited`, повторная генерация
  без `--specs` такие клубы не перезаписывает.
- Перегенерирован датасет: 4406 клубов × 6 PNG = 26436 (653 МБ) + specs.json.

## [2026-09-03] fix+feat | вертикальные полосы и связанные клубы

- **Stripes**: полосы считались по run-относительному x, из-за чего фаза сдвигалась на
  стыке «плечи/рукава → колонки торса» (полосы «изгибались»). Переведено на абсолютный x —
  полосы непрерывные вертикальные по всей текстуре (`kits/render.py`).
- **Связанные клубы** (`kits/linked.py`): клуб + академия + вторая команда объединяются в
  группу по имени (нормализация через NFKD-транслитерацию, суффиксы II/B/U19/Castilla/...,
  внутри страны). Дети наследуют полную спеку корня (палитра + 6 китов), в спеке хранится
  `linked_root`. Редактор при сохранении любого члена группы распространяет правку на всю
  группу. Найдено 339 групп (Барселона→Атлетик, Реал→Кастилья/Реал C).
- Исправлен баг нормализации: «è» в «Atlètic» без NFKD давал `atltic` ≠ суффиксу `atletic`.
