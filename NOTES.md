# GameplayFootball: что нужно изменить в игре для китов

## Набор китов

Генератор производит **6 комплектов** на клуб:
`images_teams/<league_id>/<club_id>_kit_main/white/black/reserve/gk1/gk2.png`.

Игра сейчас (`src/onthepitch/team.cpp:85-92`, `SetKitNumber` в `team.cpp:557`) умеет только
`_kit_01.png`/`_kit_02.png` и общий `goalie_kit.png` для вратаря. Для полного набора нужны:

- **team.cpp:85-92** — грузить набор файлов (`_kit_main.png` и т.д.) вместо `_kit_0N.png`;
- **SetKitNumber / выбор кита** — принимать имя комплекта, а не номер 1/2;
- **вратарь** — вместо жёсткого `goalie_kit.png` брать `_kit_gk1.png`/`_kit_gk2.png`.

## Выбор китов на матч

Эталон алгоритма — `kits/spec.py::pick_match_kits(a, b, manual)`:

- **конвенция**: команда A (home) в `main`; команда B (away) тоже в `main`, но если её
  `main` клашится с футболкой A — B переодевается в самый контрастный из своих
  `white/black/reserve`; если пара всё ещё клашится — переодевается и A;
- **manual** `{"a": kit, "b": kit}` — принудительный выбор (пункт меню / UI);
- **вратари**: каждый гк из `gk1`/`gk2` — тот, что максимизирует мин-контраст к обеим
  выбранным полевым футболкам.

Контраст — евклидово расстояние RGB между цветами футболок; клаш при < 60.

Алгоритм маленький (4×4 по полевым + 2×2 по вратарям), переносится в C++ целиком.
Рекомендация: вычислять на старте матча в меню (там уже есть обе команды) и передавать
выбранные комплекты в `Team` (аналог `GetTeamKitNum`).

## Цвета радара

`teams.color1/color2` (`teamdata.cpp:84-85`, радар `match.cpp:306`) — класть из `main`
кита (футболка/шорты) в формате `"R, G, B"` (см. `GetVectorFromString`).

## template_kit.png

Не меняется — регионы выводятся из него программно (`kits/regions.py`):
футболка y 0–418, шорты y 419–582, гетры y 583–766.
