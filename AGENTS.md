# kit-generator

Генератор комплектов формы (kit) для GameplayFootball из данных Transfermarkt: цвета из
профиля клуба на TM, при отсутствии — из логотипа. Два этапа: пакетная генерация скриптом
(`generate_kits.py`) и ручной редактор (`editor/server.py`), в котором клуб за клубом
показываются логотип и цвета, а раскладка по частям формы (футболка/шорты/гетры) и узор
футболки назначаются схематично.

## Термины

- **Кит-спека** — JSON-описание комплектов клуба: палитра + по частям (shirt/shorts/socks)
  и комплектам (home/away/gk) индексы цветов, узор футболки.
- **Палитра клуба** — упорядоченный список цветов: профильные TM-цвета, затем извлечённые
  из логотипа, затем нейтрали (белый/чёрный).
- **Регионы шаблона** — области `template_kit.png`: футболка (color1-регион, y 0–418),
  шорты (color2 y 420–580), гетры (color2 y 584–766), швы/фон (чёрное).
- **Затенение** — зелёный канал шаблона несёт яркость трикотажа: результ = цвет_региона × (G/база).
- **Логотип-палитра** — топ цветов из логотипа (ресайз, игнор прозрачности, квантование),
  используется когда в профиле TM нет цветов или нужен дополнительный.

## Как это работает

```
data_max/full/clubs.json + images/logos/<id>.png
   + template_kit.png (из GameplayFootball)
   ▼
palette: профильные цвета -> логотип -> нейтрали
   ▼
автоподбор спеки (home/away/gk по контрасту)
   ▼
render: регионами + узор + затенение -> PNG 1024×1024
   ▼
editor: обзор клубов, правка спек, перегенерация PNG
```

Игра ожидает файлы `_kit_01.png` (home) и `_kit_02.png` (away) по пути из `teams.kit_url`,
вратарский — сейчас общий `goalie_kit.png`; пер-тим GK-киты требуют правки `team.cpp`
(см. `NOTES.md`).

## Конвенции

- Код и комментарии — английский; этот файл и документация — русский.
- Спеки хранят индексы в `palette`, а не HEX — чтобы ручная правка не разъезжалась
  с извлечёнными палитрами.
- Детерминизм: без RNG, хэши для разброса не используются; один и тот же вход даёт один
  и тот же выход.
